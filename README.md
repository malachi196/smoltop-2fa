# SmolTO(t)P 2FA

> [!WARNING]
> SmolTOP is still a work in progress, and does not work yet!
> (although a working version will be done very shortly)

SmolTO(t)P is a Time-based One Time Pass (TOTP) 2 Factor Authentication (2FA) tool that is designed to be very small (smol), and relatively lightweight. This helps make it portable and convenient at a moment's notice, without using too many system resources. SmolTOP accomplishes all this *completely* for free, as Free and Open Source Software (FOSS)!
